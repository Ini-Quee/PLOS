## 🚀 To Add More Images:

**For each new image:**

1. **Download/Save it**
2. **Rename it** (e.g., `rain-cozy-window.jpg`)
3. **Move to correct folder:**
   - Rain → `public/images/backgrounds/rain/`
   - Snow → `public/images/backgrounds/snow/`
   - Forest → `public/images/backgrounds/forest/`
   - Ocean → `public/images/backgrounds/ocean/`
   - Mountain → `public/images/backgrounds/mountain/`
   - Desert → `public/images/backgrounds/desert/`
   - Sunset → `public/images/backgrounds/sunset/`

4. **Tell me:** "I added [filename] to [folder]"
5. **I'll update** the code to include it!
